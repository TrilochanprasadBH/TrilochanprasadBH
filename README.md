## 🚀 Selected Projects

### [ScoreResume](https://scoreresume.com)
_AI-powered resume intelligence SaaS · Solo-built_

Transforms resumes into measurable career outcomes — ATS readiness, interview performance, and job-fit intelligence.

- Built an async AI processing pipeline with BullMQ and Redis, including retries and a dead-letter queue to handle failed jobs.
- Developed a RAG system with pgvector, LangChain, and Gemini for multi-dimensional scoring and semantic resume-to-job-description matching.
- Designed a multi-tenant PostgreSQL schema with per-user data isolation and free/paid feature gating.
- Integrated DodoPayments billing with webhook signature validation and idempotent event processing.
- Deployed on Hetzner with CI/CD, Cloudflare CDN, Sentry, and PostHog.

**Results:** 18,000+ organic pageviews · 25+ paying users · <200ms p95 API latency · 99%+ uptime · 90+ Web Vitals

**Stack:** Next.js, TypeScript, PostgreSQL, pgvector, BullMQ, Redis, LangChain, Gemini

### [AttemptIQ](https://attemptiq.com)
_UPSC diagnostic analytics platform · Solo-built_

Transforms mock test performance into actionable readiness insights for serious aspirants.

- Designed a 23-table PostgreSQL schema with 5 materialized views to model question-level performance, topic mastery velocity, and trap susceptibility.
- Built an async AI insight pipeline with BullMQ for non-blocking, personalized report generation.
- Implemented RAG-based insights with pgvector, using a user's historical performance to surface targeted improvement loops.
- Tracks answer-reversal patterns, time-pressure fatigue, and topic confidence decay across sessions.
- Built multi-tenant architecture with JWT authentication, rate-limited endpoints, and per-user data isolation.

**Results:** 12,000+ organic pageviews · 15+ paying users · <200ms p95 API latency · 99%+ uptime · 90+ Web Vitals

**Stack:** Next.js, Node.js, PostgreSQL, pgvector, BullMQ, JWT, Gemini
